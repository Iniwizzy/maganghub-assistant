MagangHub Assistantv1.0.0

Laporan harian MagangHub dari 1 kalimat

Ekstensi browser gratis untuk peserta magang. Gemini menulis tiga kolom laporan, kamu periksa, lalu sekali klik masuk ke form. Ada pengingat lewat notifikasi browser dan WhatsApp juga.

Download ekstensi Panduan lengkap

v1.0.0 · 34,7 KB · Chrome atau Edge di laptop/PC

Sedang direview di Microsoft Edge Add-ons. Sambil menunggu, pasang manual dengan langkah di bawah.

Pasang dalam 6 langkah

  1. Download dan ekstrak

    Klik Download ekstensi, lalu ekstrak zip-nya (Windows: klik kanan → Extract All…) ke folder tetap, misalnya Documents\MagangHub Assistant. Jangan hapus atau pindahkan folder ini nanti.

  2. Buka halaman ekstensi

    Ketik chrome://extensions (Chrome) atau edge://extensions (Edge) di address bar.

  3. Nyalakan Developer mode

    Chrome: sakelar di kanan atas. Edge: sakelar di panel kiri bawah. Di browser berbahasa Indonesia namanya kurang lebih Mode pengembang.

  4. Klik Load unpacked

    Pilih folder hasil ekstrak, yang di dalamnya langsung ada manifest.json. Lalu sematkan ikonnya lewat ikon puzzle di toolbar.

  5. Tempel API key Gemini

    Buat key gratis di aistudio.google.com/apikey. Di ekstensi: tab Pengaturan → tempel → Simpan & tes koneksi.

  6. Hubungkan WhatsApp (opsional)

    Tab Pengingat → Hubungkan WhatsApp → kirim pesan DAFTAR yang muncul. Balas sudah untuk berhenti hari itu, STOP untuk berhenti total.

Setiap hari

  1. Buka form laporan hari ini

    Login ke monev.maganghub.kemnaker.go.id seperti biasa.

  2. Tulis 1 kalimat

    Tab Laporan → ceritakan kegiatanmu → Buat laporan dengan AI. Tiga kolom muncul, masing-masing lebih dari 100 karakter.

  3. Periksa, lalu isi ke form

    Edit seperlunya, klik Isi ke form MagangHub.

  4. Kirim sendiri

    Baca ulang di MagangHub, centang pernyataan, klik Simpan dan Kirim. Ekstensi tidak pernah mengirim laporan untukmu.

Lainnya

Update ke versi baru
  1. Download zip versi baru.
  2. Ekstrak ke folder yang sama, timpa file lama. Folder harus sama supaya pengaturan dan sambungan WhatsApp tidak hilang.
  3. Di halaman ekstensi, klik tombol muat ulang (panah melingkar) di kartu MagangHub Assistant.
Pindah ke versi toko setelah rilis
  1. Kalau WhatsApp terhubung: tab Pengingat → Putuskan dan hapus nomor dari server.
  2. Hapus versi manual (Remove) dan foldernya.
  3. Pasang dari Microsoft Edge Add-ons, isi API key dan hubungkan WhatsApp lagi.

Jangan pasang dua versi sekaligus, karena pengingat bisa dobel.

Privasi

API key dan teks laporan disimpan di browser-mu. Teks aktivitas hanya dikirim ke Google Gemini saat kamu menekan Buat laporan dengan AI. Nomor WhatsApp hanya disimpan kalau kamu menghubungkan WhatsApp, dan bisa dihapus kapan saja. Ekstensi hanya berjalan di monev.maganghub.kemnaker.go.id.

Baca kebijakan privasi lengkap

Ekstensi independen, tidak berafiliasi dengan Kemnaker atau MagangHub. Pastikan isi laporan sesuai kegiatanmu yang sebenarnya.
